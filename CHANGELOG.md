# Changelog

Both plugins share a version number. The Unity package keeps its own
detailed changelog in [unity/com.particlefx.studio/CHANGELOG.md](unity/com.particlefx.studio/CHANGELOG.md).

## 0.1.1 - 2026-10-25

- Godot: the dock's posters and cards follow the editor display scale, so
  titles no longer clip on Retina and 4K screens; two columns fit the
  default dock width.
- Unity: documentation, changelog and licence links point to this repository.
- Tested end to end against the plugin API on Godot 4.7.1 and Unity 6000.0.

## 0.1.0 - 2026-10-19

- First release: Godot 4.2+ add-on and Unity 2021.3+ package. Browse the
  library and your own effects, import with one click, offline zip import.
